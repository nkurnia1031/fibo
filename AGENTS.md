## Agent skills

Use `main` as the default branch for all work. Use another branch only when the user explicitly asks for it.

Issues are tracked in GitHub Issues using `gh`. See `docs/agents/issue-tracker.md`.

Uses the default canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs
