# Vue admin application

This is the API-backed Vue 3 staff panel for Fibo TKA Math. It is served by Laravel on the product domain. The GitHub Pages homepage is the separate, fixture-backed student experience prototype; the Pages copy of this admin app still requires a backend session and is not the student demo.

See the root [README](../../README.md) for local commands, the [MVP specification](../../docs/specs/tka-math-admin-mvp.md), and [implementation tickets](https://github.com/nkurnia1031/fibo/issues/1).
