# Vue admin demo

This is the fixture-backed Vue 3 interface for the Fibo TKA Math Admin MVP. It is intentionally usable without Laravel/MySQL so reviewers can open the GitHub Pages demo directly.

See the root [README](../../README.md) for local commands, the [MVP specification](../../docs/specs/tka-math-admin-mvp.md), and [implementation tickets](https://github.com/nkurnia1031/fibo/issues/1).
